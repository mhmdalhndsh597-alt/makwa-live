# ماكوا لايف | Makwa Live

تطبيق ويب تقدّمي متوافق مع الهاتف أولًا لخدمة غسيل الملابس والكي بالبخار، بواجهة عربية مصرية كاملة واتجاه RTL. المستودع خاص ويُستخدم لحفظ مصدر المشروع والتقدم على مراحل.

## حالة المشروع

قيد التنفيذ. المواصفات وخطة التنفيذ وسجل العمل محفوظة في هذا المستودع قبل بدء بناء التطبيق، وسيُحدّث السجل مع كل مرحلة محفوظة.

## الملفات والوثائق

| الملف أو المسار | الغرض |
| --- | --- |
| `README.md` | تعريف المشروع، شرح المجلدات والملفات المهمة، وبيان حالة التسليم |
| `plan.md` | قرارات التصميم والتنفيذ وبنية التطبيق |
| `TODO.md` | متطلبات المنتج مجزأة إلى نتائج قابلة للتسليم وحالة إنجازها |
| `WORKLOG.md` | سجل مؤرخ للتغييرات والقرارات والتسليمات المرحلية |
| `src/` | شفرة الواجهة وتجارب المستخدم والمكوّنات |
| `server/` | واجهات الخادم للخصائص التي تحتاج إلى معالجة آمنة، ومنها مساعد الذكاء الاصطناعي |
| `public/` | الأيقونات وملف PWA وملف `manus-routes.json` وموارد الواجهة الثابتة |

ستُضاف الملفات الفعلية إلى هذا الجدول عند اعتماد هيكلها في المشروع.

## تشغيل المشروع

ستُضاف أوامر التثبيت والتشغيل والبناء هنا بعد تثبيت قالب التطبيق وتأكيد أوامره.

## ملاحظات البيانات والخصوصية

- تُستخدم بيانات مصرية تجريبية لتوضيح مسار الاستخدام؛ لا تمثل طلبات أو عملاء حقيقيين.
- الصور التي تُنشأ للمظهر التجريبي يجب وصفها بوضوح بأنها توضيحية، لا باعتبارها صورًا حقيقية مباشرة من المغسلة أو من طلب عميل. تُستبدل بصور يزوّد بها صاحب المشروع قبل الإطلاق التجاري.
- لا تُحفظ كلمات مرور أو مفاتيح أو بيانات اعتماد داخل Git. هذا المستودع خاص، لكن خصوصية المستودع لا تجعل تخزين الأسرار آمنًا.
- يمكن استكمال المشروع من المستودع وقراءة `WORKLOG.md` و`TODO.md` لمعرفة آخر نقطة وصل إليها العمل.
